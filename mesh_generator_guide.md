# Implementation Guide: StyleSpace2 AI Asset Pipeline

**Context:**
We are extending an existing React/Three.js/Vite project ("StyleSpace2") to include generative AI features.
**Goal:** Allow users to generate textures and 3D assets in-game using local ComfyUI workflows.
**Current Stack:** React 19, Three.js, @pixiv/three-vrm, Tailwind.
**New Requirement:** A Node.js Backend is required to bridge the Game Client and ComfyUI.

---

## 1. Architecture Overview
*   **Frontend (React):** Sends prompts/params → Polls for status → Downloads ZIP/GLB → Applies to Avatar.
*   **Backend (Node.js/Express):** Validates request → Modifies ComfyUI JSON → Triggers ComfyUI → Watches for Output → Zips files → Serves URL.
*   **ComfyUI (Local):** Runs the workflows via API (`/prompt` endpoint) or Watch Folder.

---

## 2. Backend Implementation (New Service)
**Stack:** Node.js, Express, `adm-zip` (zipping), `multer` (file upload), `axios` (ComfyUI communication).

### **Todo 2.1: Server Setup**
*   Initialize `server.js`.
*   Setup Static File Serving:
    *   `/input` (Images uploaded by user).
    *   `/output` (Images generated by ComfyUI).
    *   `/archive` (Final ZIPs).
*   **Endpoints:**
    *   `POST /api/generate`: Accepts JSON `{ workflowType, prompt, params, seed }` + File (optional UV template).
    *   `GET /api/status/:jobId`: Returns `{ status: 'queued'|'processing'|'done', outputUrl: string }`.

### **Todo 2.2: ComfyUI Bridge Controller**
*   **Load Template:** Read the provided `.json` workflow templates (`uv_texture`, `turnaround`, `depth`).
*   **Inject Data:** Create a function to parse the JSON and replace specific node values:
    *   *Seed Node:* Set `seed`.
    *   *Z-Image/KSampler:* Set `text_positive`.
    *   *Image Loaders:* Set `image_path` (absolute server path).
    *   *Image Savers:* Set `filename_prefix` with JobID.
*   **Trigger:** Send the modified JSON payload to ComfyUI API: `POST http://127.0.0.1:8188/prompt`.
*   **Track:** Store the `prompt_id` returned by ComfyUI to track progress.

### **Todo 2.3: Post-Processing & Zipping**
*   **Watcher:** Implement a polling loop or event listener checking the ComfyUI output directory.
*   **Condition:** When all expected files for `jobId` exist:
    1.  Use `adm-zip` to archive them into `jobId.zip`.
    2.  Move ZIP to `/archive`.
    3.  Update Job Status to `done`.

## 3. Frontend Implementation (React/Three.js)

### **Todo 3.1: UI Components (`/src/components/ui/Creator`)**
*   **PromptPanel:** Textarea for prompt + Sliders (Steps, Cfg) + FileInput (for UV/Depth base).
*   **StatusIndicator:** Visual feedback for "Queueing", "Generating", "Downloading".
*   **ResultPreview:** Display the generated PNGs before applying.

### **Todo 3.2: API Integration Hook (`useAIAsset.ts`)**
*   `submitJob(prompt, type, file?)`: Uploads data to Backend.
*   `pollStatus(jobId)`: Checks status every 2s. Returns download URL when complete.

### **Todo 3.3: 3D Asset Logic (`/src/utils/assetLoader.ts`)**
*   **Texture Workflow:**
    *   Fetch generated image (Blob).
    *   `new THREE.TextureLoader().load(url)`.
    *   Target specific VRM material (e.g., `avatar.traverse` -> find material by name -> `mat.map = texture`).
    *   Set `material.needsUpdate = true`.
*   **Mesh/GLB Workflow:**
    *   Fetch GLB/ZIP.
    *   If ZIP: Use `adm-zip` (or `fflate`) client-side to extract `.glb`.
    *   Use `GLTFLoader` to parse.
    *   Attach to avatar bone (e.g., `J_Bip_C_Hips` for skirts, `J_Bip_C_Head` for hair).

#### **A. How to talk to ComfyUI (Node.js)**
ComfyUI doesn't accept "files" directly in the generation request. You must upload the image first, then reference it.

```javascript
// 1. Upload Input Image (UV or Base)
async function uploadImage(fileBuffer, fileName) {
  const formData = new FormData();
  formData.append("image", fileBuffer, fileName);
  formData.append("type", "input");
  await axios.post(`${COMFY_URL}/upload/image`, formData);
}

// 2. Queue Prompt
// Note: You must modify the workflow object before sending!
async function queuePrompt(workflowJson) {
  const { data } = await axios.post(`${COMFY_URL}/prompt`, {
    prompt: workflowJson // In API format, this is the node map
  });
  return data.prompt_id;
}
```

#### **B. How to swap textures in Three.js (VRM)**
VRM avatars are standard GLTF scenes. You need to traverse the meshes to find the clothing material.

```javascript
import { TextureLoader, sRGBEncoding, FlipY } from 'three';

function applyTextureToAvatar(vrm, textureUrl, targetMaterialName) {
  const loader = new TextureLoader();
  loader.load(textureUrl, (texture) => {
    // Critical settings for GLTF/VRM
    texture.flipY = false; 
    texture.encoding = sRGBEncoding; // or LinearEncoding depending on your scene

    vrm.scene.traverse((node) => {
      if (node.isMesh && node.material) {
        // VRM avatars often have multiple materials. Find the right one.
        // You might need to check node.material.name or node.name
        if (node.material.name === targetMaterialName) {
          node.material.map = texture;
          node.material.needsUpdate = true;
        }
      }
    });
  });
}
```
